# Personal Control Hub 成品与项目贯通验收规格

- 读者：负责本 Goal 的执行者、所有者、成品验收者和未来维护者。
- 目的：把“Hub 做完、其他项目打通后再交接”变成可验证的完成条件。
- 更新触发：所有者改变成品范围、接入范围或必需能力。
- 版本：2；当前为待执行规格，不是已交付声明。

这是 [Goal prompt](../../prompts/ui_design_governance_goal_mode.md) 的完成判据，执行边界见 [执行规范](ui_governance_execution.md)。Hub 成品和实际关联是主目标，后续使用哪个执行器由所有者安排。

## 1. 做完意味着什么

用户能打开本地 Hub，找到自己的项目，看见每个项目的可信状态、下一步、来源和关联；从项目进入设计审核，对照原版与 Figma 候选，留下选择和反馈，再查到历史。更新来源后，用程序刷新即可看到变化，无需 Agent 重新读一遍、手抄摘要。其他任务可以继续运行。

本目标交付完整 Hub 和冻结范围内的真实连接，完成后写交付说明即结束。代表页面只是验证方法，不能替代全项目接入；外部代码实施也不是必需验证步骤。Hub 日常项目管理不能只剩 CLI 输出或静态假页面。

本成品包含项目管理、关联、状态读取和设计治理，保留既有有效 CLI/只读能力。主实现放在 Hub；外部默认只读，必要关联/视觉例外按执行规范的严格范围和隔离条件处理，禁止改业务功能、数据处理或他人推进中的代码。历史路线图中的飞书、付费模型、跨机器调度、远程控制、业务资产仓库和发布平台不自动纳入。

## 2. 最小而完整的界面

| 页面/能力 | 用户能完成的事 | 必需数据与反馈 |
| --- | --- | --- |
| 项目总览 | 搜索/筛选项目，辨认需要关注的项目，进入详情 | 真实项目名、类型、状态、下一步摘要、数据更新时间与不可用提示。避免大量空卡片与无用指标。 |
| 项目详情 | 看权威来源、完整下一步、阻塞和关联，打开获准的项目/设计入口 | 来源定位、原始状态及规范化含义、刷新结果、可解释关系、设计进度。诊断按需展开。 |
| 关系展示 | 知道项目为何相关、可以共用什么设计、有哪些例外 | 结构化关系及证据。默认简洁列表/局部连线，不强制大图；未知不绘成已确认。 |
| 设计审核 | 同一基线比较原版与候选、反馈、选择、回看和导出设计材料 | 按 [审核台规格](design_review_workbench.md) 实现版本绑定、过期提示、保存/导出失败恢复。 |
| 刷新与恢复 | 单项目刷新或有界刷新整个冻结范围，知道哪些成功/失败 | 读取状态、耗时/时间、来源变动、陈旧原因；一项失败不清空其他项目。 |

导航控制在“项目”和“设计”两个主入口；列表、详情和比较按需深入。桌面与手机保持关键任务可达；手机不是桌面缩略图。Hub 使用 Figma 形成整体视觉方案，不只设计一个孤立审核弹窗。先比较 2–3 个方向，由用户选择，随后统一项目页与审核页的排版、状态、组件和留白。

首版采用本地单用户模式：可靠启动/停止、刷新、持久化、错误恢复必需；公网部署不属于默认完成条件。入口与启动命令必须真实可运行并被演练，不得仅交截图或设计文件。

## 3. 全范围接入清单

激活时读取当时 registry 及适用 adapter，为每条项目记录建立 manifest 引用，冻结版本/哈希和总数。每条包含 `project_id`、管理接入范围、允许入口、权威来源、当前权限依据、预期可读能力、UI 范围判定和验收引用。路径由 registry 解析，manifest 只记录冻结证据，不成为第二份可编辑项目名册。

接入不能仅限于有 UI 的代码仓库；文档/创作项目、治理项目按其真实允许入口提供摘要或指针。不得复制业务内容。对禁读、disabled 或特殊记录核对当前策略适用范围；有明确现行策略的豁免记录原文/来源，不能把一次存储排除盲目扩大到全部管理。新的项目纳入或范围变更必须产生新 manifest 版本并说明决定来源，旧记录保留，不偷偷改分母。

每条最终只能为：

- `CONNECTED_AND_VERIFIED`：程序成功读取获准真实来源，完成摘要/来源/刷新/关系验收，有逐项证据。
- `AUTHORIZED_EXCEPTION`：所有者明确决定或适用的现有策略要求例外，记录范围、原因和依据，在界面可见；不能由 Agent 因实现困难自批。

过程中可用 `PENDING / BLOCKED_BY_AUTHORITY / SOURCE_UNAVAILABLE / VALIDATION_FAILED`，但不是完成终态。冻结范围内任何这些条目都阻止完成，除非问题解决或所有者批准范围修订；不得将必需 Hub/接入工作留给未知后续任务以虚报完成。此处的授权缺口指真实管理读取，不要求取得外部代码写入权。

## 4. 单项目怎样才算打通

1. 从稳定 project ID 经 registry/adapter 找到当前获准来源，正确处理目录迁移、软链和不可用外置盘；不随意全盘搜索，不启动项目业务任务。
2. 用实际程序读取当前项目规则允许的结构化状态或最小状态入口，生成带 provenance 的摘要。至少覆盖身份、状态、下一步、来源、观察时间、可用性与设计/关系引用。项目本来没有某字段时显示“来源未提供”及证据，不造值；不能把路径存在或 README 名称当成状态已接入。
3. 在 Hub 列表与详情看到同一摘要，能回到原始权威来源。只读观察不改变该项目的 STATE、数据库、文件格式、优先级或真实审核结论。
4. 真实只读刷新再次成功，并留下读取/指纹证据。用该来源的脱敏临时副本演练内容变化、缺失、损坏、权限失败和恢复，准确区分真实连接证据与 mock 错误分支；不为了测试修改活跃项目。
5. 关系按代码/契约/显式所有者决定取证；区分 Hub 管理连接、业务管线关系、审核模式相同和视觉家族。没有其他关系的项目也能独立工作；“无关联”须有勘察依据，未知不冒充无关联。
6. 验收命令、退出码、来源版本、刷新时间和结果可复现；手工粘贴摘要或 LLM 生成固定 JSON 不能算 adapter。

外部项目格式各异时，Codex 在 Hub 实现小型只读 adapter，统一输出摘要形状。优先代码可确定的字段；文本来源采用可重复提取和明确未知值，不要求每个项目先重构 STATE。修复 Hub 现有读取、路径和校验缺陷可以是实现工作的必要部分，但先保护并发改动、建立明确写入权和基线。

## 5. 程序化管理成品

必须交付可重跑的输入校验、单项/有界全量刷新、摘要读取、关系读取、设计候选校验、用户决定保存、过期检测和验收汇总。接口可先用本地 CLI/库/API 的最小组合，按现有 Python 结构实现，不为形式另建微服务体系。UI 使用同一读取/校验层，避免页面与 CLI 各维护一套事实。

逐项目接入记录全由命令产出或校验；标准流程在无需 Agent 参与时也能工作。schema 版本、错误处理、幂等和冲突规则按 [数据契约](ui_governance_data_contract.md)。前端不通过大模型“生成当前状态”，也不直接扫描任意路径。真实项目暂时离线时可展示最近成功快照，但显著标为陈旧，不能冒充已刷新。

每次刷新只读取冻结范围和明确文件；源项目继续自行推进。既不依靠常驻 Agent，也不要求 daemon：手动/按需刷新足以交付，自动刷新如果实现必须可控、有界且不会竞争源项目。

## 6. 成品验收与完成交付

Codex 冻结 Hub 成品版本、manifest、协议、schema/adapter、Figma 与决定身份后，独立验证：

- **全覆盖**：逐项目 ID 零遗漏/零重复，所有行都有合法终态与证据；只读真实连接不能由 fixture 替代。
- **产品闭环**：用真实冻结范围走通列表 → 详情 → 来源/关系 → 刷新 → 设计对照 → 用户选择 → 重启回看。没有设计候选的项目正确显示空状态，不凭空生成审核通过。
- **数据一致**：CLI/读取 API 与界面对应同一来源版本；缺失、未知、陈旧、错误、恢复不混淆；关联和设计家族有证据。
- **视觉和功能**：桌面/手机、键盘/焦点、可访问性、loading/empty/error/disabled、reduced motion，及 console/network 分别验证。按 UI rubric 记录，必需项 FAIL/UNVERIFIED 阻止总体通过。
- **设计工作流**：Hub 方案由用户选择并在 Hub 实现。查看真实外部 UI → Figma 候选 → Hub 比较/反馈/选择 → 历史/设计材料导出全链路可用；共享/独立规则具备证据，异常分支可用明确 mock。外部代码不必实施，不能代替用户做业务审核。
- **不干扰**：证明 task-owned diff 和输出范围，其他 Agent 工作、业务数据、服务和未交接改动保持完整。
- **交付说明**：按[完成交付说明规格](completion_handoff.md)记录成品、真实运行命令、全范围连接、数据/设计入口、证据和维护方法；在当前环境核对引用，不检查或验证其他执行器。

Hub 的新读取缺陷、残缺页面、仅规划的保存功能、未完成 adapter 和未打通的项目都必须在本目标内解决，不能提前标为完成。整体冻结候选由 fresh Judge 基于完整证据评估，再按当前 GOVERNED 合同交 Governor 决策。后续其他项目开发不成为额外门槛。
