# 学习计划首页：真实源码隔离观察

范围：`computer-study-plan/home`。2026-09-06，在 Hub 自有临时目录运行三个原字节 UI 副本；三个文件的散列与复制边界见 `baseline.json.source`。较早的五文件协议探索与三次仪器化复制分开记账。未读取生产进度、事件、反馈、存档、课程正文、数据库或凭据；未启动或写入外部项目。

数据全部由 `synthetic_data.py` 构造：Terminal 初见 / 示例练习，三项任务，当前任务“认识终端”，revision 0，0/3，路线 0%，无学习历史。五份课程路径对应的正文也是合成资料。`fixture_server.py` 仅提供明确允许的 loopback GET；写请求返回 405，禁止目录兜底与代理。界面偏好可能写入该隔离端口的浏览器存储；不写生产数据。

观察窗口为桌面 1440×1000、手机 390×844；外部信任提示占 63/105px。比较用的产品 iframe 截图分别是 **1440×937、390×739**，与两种 Figma 设计画板一致。完整窗口截图和学习页截图另留作证据。

实测：当前任务卡/主要入口进入学习页，品牌返回首页；键盘 Enter 导航；手机无横向溢出；五个手机导航依次进入 home、route、review、knowledge、growth。资料 loading → 明确注入的 HTTP 503 → 重试恢复；空记录页；记录弹窗初始焦点、Tab/Shift+Tab 循环、Escape 关闭回焦；空记录提交被校验阻止，零 POST。减少动态效果设置下仍能导航，弹窗动画关闭。明细见 `baseline-browser.json`、`baseline-states.json`。

来源默认值/语义：任务序号、模块与周次、0/3 与路线百分比表示已登记任务进度，不代表掌握或认证。历史暂无、读取失败和上次读取值不可混淆。资料加载失败提供原入口重试。当前任务标题、资料路径、进入任务/查看记录/查看路线/顶部成长及手机五导航均保留。候选只整理首页布局、信息密度和材质；学习、记录、存档、终端等后续流程不在改版范围。

Figma 中保留可编辑文本、自动布局和来源组件实例。原版是捕获后修正稳定态、应用源码字体栈中可用的 Noto Sans SC，并将按钮/导航组件化的设计复现；真实浏览器截图是对比页的原版依据。Figma 缺少 PingFang SC，macOS 订阅库导入被服务拒绝，因此使用源码衍生组件与六个本地颜色变量。未更改其他 Figma 文件。

候选“安静任务台”将任务名称放大为视觉中心，正面卡片取代大面积夸张透视，辅助信息分组，低饱和杏色按钮、柔和阴影，手机保留五导航。现有悬停、长按拖动与回位属于实施保留要求；静态 Figma 不证明运动逻辑已实现。任何后续实施不得借本稿改变任务推进、记录或数据写入规则。

边界：没有验证真实保存、完成、终端执行或真实学习进度；这些业务写入是本单元明确排除项。Figma 候选尚未写入外部项目。源码身份只绑定本次副本，不能声称外部项目此后无漂移；源码变化需建立新观察/基线。当前候选不是所有者决定。实际选稿后才记录选择、验证重启与选定导出，并提交独立验收。

捕获排障：首次原版在进入动画中冻结，复现依据稳定态修正透明度、模糊与位移；手机第一次转换读到了捕获服务器启动时缓存的桌面内容，重启并逐字核对服务正文后重做。三个捕获参考节点均已删除，最终只保留四个可编辑视图和三个来源组件。无重用已消费的 capture ID。
